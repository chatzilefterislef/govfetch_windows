# Gov Document Fetcher

Τοπική εφαρμογή που κατεβάζει αυτόματα φορολογικά έγγραφα από τα portals της
ΑΑΔΕ (TaxisNet), με σωστή ονομασία αρχείων.

| Τύπος πελάτη | Έγγραφα |
|---|---|
| Ατομική επιχείρηση | Ε1, Ε3, Εκκαθαριστικό, ΦΠΑ |
| Νομικό πρόσωπο (ΟΕ, ΕΕ, ΑΕ…) | Ν, Ε3, ΦΠΑ |

Κατεβαίνει ό,τι υπάρχει κάθε φορά: αν ένα έγγραφο δεν υπάρχει για τον
συγκεκριμένο πελάτη ή έτος, σημειώνεται και η διαδικασία συνεχίζει.

## Έτοιμο πακέτο (χωρίς Python)

Για όποιον θέλει απλώς να τη χρησιμοποιήσει, χωρίς εγκατάσταση Python:
κατέβασε το πακέτο του λειτουργικού του από τα
[Releases](https://github.com/chatzilefterislef/gov-doc-fetcher/releases),
αποσυμπίεσε, και τρέξε το `GovDocFetcher` μέσα στον φάκελο. Ο Chromium είναι
μέσα στο πακέτο — δεν χρειάζεται τίποτα άλλο.

- **Windows** → διπλό κλικ στο `Εκκίνηση.bat`. Στο SmartScreen: **More info** →
  **Run anyway**
- **macOS** → διπλό κλικ στο `Εκκίνηση.command`

Κρατήστε ανοιχτό το παράθυρο που εμφανίζεται όσο δουλεύει η εφαρμογή.

### macOS: το εμπόδιο της πρώτης εκκίνησης

Τα πακέτα δεν είναι notarized από την Apple, οπότε στο **macOS 15 και νεότερα**
εμφανίζεται παράθυρο με μόνο **«Move to Bin»** και **«Done»** — και το παλιό
κόλπο «δεξί κλικ → Open» **δεν δουλεύει πια**, η Apple το κατάργησε.

Πάτα **Done** και μετά, μία φορά μόνο, ένα από τα δύο:

```bash
# Άνοιξε Terminal, γράψε αυτό με κενό στο τέλος, σύρε τον φάκελο μέσα, Enter
xattr -dr com.apple.quarantine
```

ή **System Settings → Privacy & Security →** κύλισε κάτω στο *Security* →
**Open Anyway**.

Για να αποφευχθεί εντελώς αυτό, δες την εγκατάσταση από τον κώδικα παρακάτω: τα
αρχεία που έρχονται με `git clone` **δεν** μπαίνουν σε quarantine, οπότε δεν
υπάρχει κανένα μήνυμα.

Νέα έκδοση χτίζεται αυτόματα με tag (`git tag v1.0.0 && git push --tags`) ή
χειροκίνητα από την καρτέλα **Actions** του repository. Τοπικά, για την τρέχουσα
πλατφόρμα: `python packaging/build.py`

## Προϋποθέσεις (για ανάπτυξη)

**Python 3.9 έως 3.12.** Τίποτα άλλο — ο Chromium κατεβαίνει αυτόματα την
πρώτη φορά (~150 MB).

Η 3.13 και νεότερη **δεν δουλεύει**: το Playwright 1.47 καρφώνει
`greenlet==3.0.3`, που έχει έτοιμα wheels μέχρι την 3.12, οπότε το pip
προσπαθεί να το μεταγλωττίσει και ζητά Visual C++ Build Tools (Windows) ή Xcode
Command Line Tools (macOS). Το `run.py` το ελέγχει και σου το λέει καθαρά.
Προσοχή: το python.org προσφέρει σήμερα την 3.14 ως προεπιλογή — διάλεξε ρητά
την 3.12 από τη λίστα εκδόσεων.

- **macOS**: `python3.12 --version`. Αν λείπει: `brew install python@3.12` ή από
  το [python.org](https://www.python.org/downloads/)
- **Windows**: κατέβασε την **3.12** από
  [python.org](https://www.python.org/downloads/) και στην εγκατάσταση τσέκαρε
  **«Add python.exe to PATH»**. Έλεγχος: `py -3.12 --version`

## Εγκατάσταση και εκκίνηση

```bash
git clone git@github.com:chatzilefterislef/gov-doc-fetcher.git
cd gov-doc-fetcher
```

Μετά, μία εντολή — φτιάχνει το περιβάλλον, εγκαθιστά ό,τι χρειάζεται και ανοίγει
την εφαρμογή:

**macOS / Linux**

```bash
python3.12 run.py
```

**Windows**

```bash
py -3.12 run.py
```

Αν η 3.12 είναι η μόνη Python στο μηχάνημα, αρκεί `python3 run.py` και
`python run.py` αντίστοιχα.

Η πρώτη εκτέλεση παίρνει ένα-δύο λεπτά (κατεβαίνει ο Chromium). Οι επόμενες
είναι άμεσες. Η εφαρμογή ανοίγει στο <http://localhost:8000>.

Αν η πόρτα 8000 είναι πιασμένη: `python3 run.py --port 8001`

## Χρήση

1. Κωδικοί TaxisNet του πελάτη
2. Ονοματεπώνυμο ή επωνυμία — μπαίνει στο όνομα του αρχείου
3. Χρονολογία
4. Διακόπτης **Ατομική Επιχείρηση** — καθορίζει ποια έγγραφα ζητούνται
5. **Έναρξη Λήψης**

Θα ανοίξει ένα παράθυρο Chromium που κάνει την πλοήγηση μόνο του· άφησέ το να
δουλέψει. Η πρόοδος φαίνεται ζωντανά στην εφαρμογή και στο τέλος βγαίνει σύνοψη:
τι κατέβηκε, τι δεν υπήρχε, τι απέτυχε.

Τα PDF αποθηκεύονται στο `~/Downloads/GovDocs` (στα Windows:
`C:\Users\<όνομα>\Downloads\GovDocs`).

## Μέσα από Claude Code

Το repo έχει έτοιμο preview config. Άνοιξε τον φάκελο με Claude Code και ζήτα
«ξεκίνα την εφαρμογή» — θα χρησιμοποιήσει το `.claude/launch.json`. Υπάρχουν δύο
configurations, `gov-doc-fetcher` για macOS/Linux και `gov-doc-fetcher (windows)`.

Το [CLAUDE.md](CLAUDE.md) περιέχει τη δομή του κώδικα και τις παγίδες των portals
της ΑΑΔΕ, ώστε ο Claude να μη ξανακάνει λάθη που έχουν κοστίσει χρόνο.

## Όταν κάτι χαλάει

Κάθε τρέξιμο γράφει αναλυτικό log με τα βήματα, τα URL και τα κουμπιά που
βρέθηκε σε κάθε σελίδα:

```bash
cat /tmp/gov_doc_fetcher.log
```

Στα Windows είναι στον προσωρινό φάκελο — δες τη διαδρομή που τυπώνει η
εφαρμογή. Δίπλα υπάρχουν screenshots `gov_debug_*.png` από τα σημεία που
απέτυχαν. Στείλε αυτά τα δύο και το πρόβλημα εντοπίζεται γρήγορα.

Τα portals της ΑΑΔΕ αλλάζουν κάθε τόσο, οπότε κάποιο βήμα μπορεί να χρειαστεί
προσαρμογή· το log δείχνει ακριβώς πού.

## Ασφάλεια

Όλα τρέχουν τοπικά στον υπολογιστή σου. Οι κωδικοί TaxisNet χρησιμοποιούνται
μόνο για το login και **δεν αποθηκεύονται** — ούτε σε αρχείο, ούτε στο log.

Τα κατεβασμένα PDF είναι φορολογικά στοιχεία πελατών. Το `.gitignore` αποκλείει
τα `*.pdf`, ώστε να μη ανέβουν ποτέ κατά λάθος στο repository.
